# Referencia de interfaz
Objetivo: conservar el panel existente y permitir su uso en teléfonos.
Referencia principal: index.html del proyecto original del usuario.
Se conservan Arial, fondo #0f172a, tarjetas #111827, radios de 14 px y el mapa Leaflet.
Los colores rojo y verde siguen indicando el resultado de una lectura reciente; gris indica desconocido/desactualizado.
La guía Refero craft-details aporta foco visible, etiquetas explícitas y controles táctiles.
Decisiones: una columna hasta 640 px (pantallas pequeñas); desplazamiento horizontal solo dentro de la tabla;
no mostrar "sin obstáculo" antes de recibir datos; fecha del servidor para distinguir datos antiguos;
fallo del proveedor del mapa no impide mostrar distancia ni historial.
No se propone una nueva dirección visual ni una nueva marca.
